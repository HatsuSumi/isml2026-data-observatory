项目前端开发规范

核心思想：减少浏览器回流和重绘，防范 XSS 风险，提升代码可维护性与执行效率。

1. DOM 节点创建

少用大段 innerHTML，固定结构优先写在 <template> 中，再通过 cloneNode(true) 克隆。

不推荐

拼接 HTML 字符串，或在循环中逐个创建复杂 DOM。

推荐

模板只解析一次，结构和样式分离，克隆后用 textContent 填入内容。

<template id="user-card">
  <div class="card">
    <span class="name"></span>
    <span class="desc"></span>
  </div>
</template>
const template = document.getElementById('user-card');
const clone = template.content.cloneNode(true);
clone.querySelector('.name').textContent = '张三';
container.appendChild(clone);

2. 渲染函数返回值

render 函数尽量返回 Node 或 DocumentFragment，不返回 HTML 字符串。

export function renderCard(data) {
  const template = document.getElementById('card-template');
  const fragment = template.content.cloneNode(true);
  fragment.querySelector('.name').textContent = data.name;
  return fragment;
}

3. 样式修改

状态切换优先使用 classList，动态数值使用 CSS 变量，减少直接写入多个 style.xxx。

:root { --theme-color: blue; }
.active { color: var(--theme-color); }
.highlight { background: yellow; }
element.classList.toggle('active');
document.documentElement.style.setProperty('--offset', value + 'px');

4. 批量插入 DOM

大量节点插入时先进入 DocumentFragment，最后一次性挂到容器，避免循环中反复触发布局计算。

const fragment = document.createDocumentFragment();

items.forEach(item => {
  const node = itemTemplate.content.cloneNode(true);
  node.querySelector('.list-item').textContent = item.name;
  fragment.appendChild(node);
});

list.appendChild(fragment);

5. 事件监听

列表、菜单等重复元素优先使用事件委托，只在父容器绑定一次监听。

const list = document.getElementById('list');

list.addEventListener('click', (event) => {
  const item = event.target.closest('li');
  if (!item) return;
  console.log('点击了：', item.textContent);
});

6. 定时动画

动画和高频视觉更新使用 requestAnimationFrame，不要用固定间隔模拟帧率。

function animate() {
  moveElement();
  requestAnimationFrame(animate);
}

requestAnimationFrame(animate);

7. 数据处理

读取深层数据用可选链和空值合并；多分支业务优先用策略映射。

const name = data?.user?.info?.name ?? '游客';
const count = data?.count ?? 0;

const strategyMap = {
  1: () => runFirstStrategy(),
  2: () => runSecondStrategy(),
  default: () => runDefaultStrategy()
};

const execute = strategyMap[type] ?? strategyMap.default;
execute();

8. 数据请求

缓存要按数据特性设计：静态数据会话复用，动态列表设置 TTL，实时数据不缓存。

const cache = new Map();

function fetchWithCache(key, fetcher, ttl = 5 * 60 * 1000) {
  const cached = cache.get(key);
  if (cached && Date.now() - cached.time < ttl) {
    return Promise.resolve(cached.data);
  }

  return fetcher().then(data => {
    cache.set(key, { data, time: Date.now() });
    return data;
  });
}

9. 列表更新

列表变化时基于 data-id 做精准更新，尽量不要整块清空重渲染。

function updateList(container, items) {
  const nextIds = new Set(items.map(item => String(item.id)));

  items.forEach(item => {
    const node = container.querySelector(`[data-id="${item.id}"]`);
    if (node) {
      updateExistingNode(node, item);
      return;
    }
    container.appendChild(createNode(item));
  });

  container.querySelectorAll('[data-id]').forEach(node => {
    if (!nextIds.has(node.dataset.id)) node.remove();
  });
}

10. 交互反馈

根据场景选择 Debounce、Throttle 或 RAF，避免一刀切处理高频交互。

场景策略时机
搜索框输入Debounce300ms
滚动 / resizeThrottle100ms
拖拽 / 动画requestAnimationFrame跟随屏幕刷新率
按钮连点Debounce500ms

代码审查清单

  • 是否存在大段 innerHTML 赋值或模板字符串拼接用户数据？
  • render 开头的函数是否返回 Node / Fragment 而非 String？
  • 是否有超过 3 层以上的三元运算符或 if/else 嵌套？
  • 循环内是否直接操作 DOM？
  • 列表渲染是否使用事件委托？
  • 动画效果是否使用 requestAnimationFrame？
  • 数据请求是否设计了合适缓存策略？
  • 列表数据变化时是否基于 data-id 最小化更新？
  • 搜索、滚动、拖拽、按钮提交等高频交互是否使用了合适策略？
