站长留言

1. 欢迎来到我个人开发的ISML 2026数据观测网站，负责2026赛季的数据统计，数据分析，数据对比，数据可视化。初衷是做出最详细的世萌数据统计。在此之前，我也尝试过多种展现数据的方式：有图文形式，有视频形式，有发帖形式，但总感觉还差点什么（交互性：你直接点我名得了）。最终，我决定以网页形式展现。

2. 本站所有数据均来自 ISML 官网 ，每场比赛结束后都会更新，因为是独立开发，所以不保证会第一时间更新。

4. 本项目是自2024赛季数据可视化项目停更以来的一个推翻重来的项目，也有可能因为时间精力成本和抑郁症的原因再次停更，但我还是想推翻重来，至少我踏出第一步了。

6. 目前网站部署在 GitHub Pages 上，开源地址: GitHub 仓库 。

7. 因为缺少服务器，所以目前是静态网站，未来有计划将升级成动态网站，主要增加「萌战应援板块」，您随时可以通过下方赞助支持来帮助站长加速实现这个目标。

8. 如果大家有任何建议、意见、bug，可以通过 hatsusumi-moe@163.com 联系我。

9. 建议使用电脑端谷歌浏览器打开，移动端和其他浏览器一定会有兼容性问题，因为一人开发，忙不过来，因此没有适配移动端布局。

10. 如果你喜欢本站，可以 复制链接 分享给更多人，也可以通过下方来支持我。

11. 个人网站，作品集：https://hatsusumi.github.io/FinalTestamentProofILived/ 。
